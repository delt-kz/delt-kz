# Про себя

Full-Stack Developer в NITEC.
Разрабатываю и поддерживаю веб-приложения, работаю как с backend, так и с frontend-частью. Основной стек — Java и Spring-экосистема: Spring Boot, Spring Data, Spring Security, JPA/Hibernate. Работаю с PostgreSQL, REST API, Docker и Git.
Имею опыт разработки и сопровождения корпоративных информационных систем, работы с существующим кодом и бизнес-логикой, интеграции сервисов и взаимодействия в команде.
Также участвовал в разработке медицинской информационной системы: разработка API, работа с базой данных, code review и миграция части функционала с монолитной архитектуры на микросервисы.
В GitHub представлены учебные, pet-проекты и практические работы.
